# stock-dashboard

一个给自己用的股票快速决策看板。输入代码，产出双轴评分、财报排雷、技术面判断和带推导过程的三个价位。

覆盖 A 股、港股、美股。同一份源码同时装进 Claude Code 和 Codex。

```
帮我看看 600519
```

真实输出（2026-09-13 实跑，排版由模型按契约渲染，数据与措辞来自脚本）：

> **600519 贵州茅台 ¥1275.16**
>
> 质量 96.74 / 时机 37.73 → **加入候选池，等技术面转好**
>
> 基本面达标但技术面未转好，等趋势确认再谈。
>
> | 买入区间 | 目标价 | 止损价 |
> |---|---|---|
> | 1168.63 ~ 1298.32 | 1361.76 | 1253.36 |
>
> 证据：十条红旗核查到 3 条（均未命中），质量分由 3/5 个维度构成（护城河、估值水平未计算），一票否决本次有效，净现比这条具备否决权的红旗已实际核查。

最后那行证据说明是强制的，缺了不合契约。它存在的唯一理由，是不让你只看见 96.74 就下单。

那句「基本面达标但技术面未转好」不是模型的措辞，是代码算出来的，换个模型渲染也不会变味。

## 设计立场

做这个东西时反复撞上同一个问题：**一个看起来很权威的数字，背后可能什么都没有。**

所以整套系统的取舍都偏向同一个方向。

**双轴不合并。** 质量轴回答「值不值得拿」，时机轴回答「现在是不是时候」。两者平均成一个数会掩盖最需要看见的情况：好公司在坏时候，或者烂公司在强势里。两轴矛盾时必须写出矛盾句，不允许调和成模糊的「持有」。

**证据量跟着分数走。** 质量分不是凭空的 96.74，它同时携带「由几个维度算出」和「十条红旗查到几条」。自检会拦截建立在单薄证据上的乐观结论。开发期实测过一个场景：十条红旗只查到一条、五个维度只算出一个，输出是「质量分 100，基本面达标」，自检全绿。现在这条路被堵死了。

**宁可承认没有，不拿近似冒充。** 港股美股没有五年市盈率历史，估值锚直接省略，买入区间纯由技术面决定并写明这一点。曾经有一版用「现价乘 0.85 到 1.20」冒充估值锚，算出来的区间和技术锚完全重合，等于什么都没做，已经删掉。

**每个价位都带推导式。** 不允许直接报数字。

```
估值锚（当前 PE(TTM) 19.57，处于历史 5.4 分位，1220 个交易日中
25 分位 PE 21.21、75 分位 PE 37.76，按现价 × 分位PE/当前PE 换算
得 [1381.84, 2459.69]）；技术锚 [1168.63, 1298.32] 取交集
```

**「未获取到」是个很重的词。** 它只用于数据源确实拿不到，绝不用于抓到了却在解析层丢掉。红旗显示未获取到，意思是从没查过，不是查过没问题。

## 你必须知道的三条限制

这三条写在 SKILL.md、写在方法论文档、写在每一份报告里。放在 README 显眼处，因为它们直接决定你该多信任输出。

**十条财务红旗里五条永远查不到。** 扣非占比、审计意见、股权质押、退市风险、立案调查，当前管线没有数据源。

六条否决路径里，四条（审计意见、质押、退市、立案）因此**永久失效**，只剩净现比连续两年低于 0.5 和大存大贷这两条可能生效。A 股实测能查到净现比，所以否决机制对 A 股是部分有效的；港股美股因为财报字段映射更弱，实际能核查的更少。

每份报告都会写明本次哪些否决项真正生效。看到「无红旗」时要分清是查过没问题，还是根本没查。实测茅台查到 3 条，苹果 4 条。

**质量分只由三个维度算出。** 护城河和估值水平两个维度从未实现计算，分数在剩下三个维度上归一化。

**估值锚只对 A 股有效。** 数据来自 2018 年至今两千多个交易日的市盈率序列。港股美股省略。

另有几条较小的：北交所没有财报数据源；北向资金日频明细自 2024-08-19 起官方停止披露，任何位置都不会出现；akshare 内部请求绕开限速器，东财调用上限只覆盖直接调用。

## 快速开始

```bash
git clone https://github.com/JosephQ47/stock-dashboard-skill.git
cd stock-dashboard-skill
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r skills/stock-dashboard/requirements.txt
powershell -ExecutionPolicy Bypass -File skills/stock-dashboard/install.ps1
```

安装脚本在两处创建目录联接，指向同一份源码，改一处两端生效。可以重复执行；遇到真实目录会终止而不是删除。

```
~/.claude/skills/stock-dashboard  ──┐
                                    ├──> skills/stock-dashboard/
~/.codex/skills/stock-dashboard   ──┘
```

**必须用项目虚拟环境。** 装进 Anaconda base 会把 numpy 升级，连带 pandas 和 pyarrow 无法导入。开发期真的这么干过一次。

代码格式随便写，`600519`、`600519.SH`、`00700`、`AAPL`、`920819` 都认。

## 双轴评分

| 质量轴 | 权重 | | 时机轴 | 权重 |
|---|---|---|---|---|
| 财报质量与排雷 | 30 | | 趋势 | 30 |
| 盈利能力与成长 | 25 | | 动量 | 25 |
| 财务健康 | 15 | | 量能与资金 | 20 |
| 护城河 *未实现* | 15 | | 位置 | 15 |
| 估值水平 *未实现* | 15 | | 催化与情绪 *未实现* | 10 |

两轴各以 60 分为界，45 分是短线博弈与彻底回避的分界：

| | 时机 ≥ 60 | 时机 < 60 |
|---|---|---|
| **质量 ≥ 60** | 重点关注，可建仓 | 加入候选池，等技术面转好 |
| **质量 < 60** | ≥45 短线博弈，<45 回避 | 回避 |

**一票否决前置于评分。** 非标审计、立案调查、退市风险、连续两年净现比低于 0.5、大存大贷、质押超 50%，命中任意一条，质量分封顶 40 且强制回避。

## 数据源

优先级来自 2026-09-13 的实测，不是纸面假设。

| 数据 | 首选 | 降级 |
|---|---|---|
| A 股行情 | 腾讯 | 东财 |
| A 股 K 线 | baostock | 东财 |
| A 股三表 | akshare 新浪源 | 巨潮人工核查 |
| A 股市盈率历史 | akshare 东财源 | 无 |
| 港股行情 | 腾讯 | yfinance |
| 美股行情与财报 | yfinance | SEC EDGAR |
| 公告 | 巨潮（POST） | 交易所 |

**东财永远排在最后。** 实测中它按源 IP 整体限流，首轮可用的接口几分钟后全部不可达，akshare 封装和裸 HTTP 表现一致。腾讯和 baostock 在同一时段始终稳定。因此降级链里不允许出现两个东财源，否则等于没有降级。

取数失败时先运行环境自检，它会逐个探测并告诉你哪些源当前可用：

```bash
.venv\Scripts\python.exe skills/stock-dashboard/scripts/doctor.py
```

## 架构

取数与计算严格分离，中间用 JSON 文件通信，每一步可单独重跑和人工检查。

```
doctor.py        环境与数据源自检
    │
fetch_data.py    市场识别 → 降级链 → {code}_raw.json
    │
compute.py       指标、红旗、双轴评分、价位 → {code}_computed.json
    │
selfcheck.py     出报告前的一致性检查
    │
             报告落盘，聊天只回摘要卡片
```

`sources_*` 只管取数不做计算，`compute` 只吃 JSON 不联网。指标、比率、评分、价位四层全是纯函数，可完全离线单测。

```
skills/stock-dashboard/
├── SKILL.md          触发条件、五步流程、硬规则
├── references/       七份方法论文档，模型运行时按需读取
├── scripts/          13 个脚本
├── tests/            276 个测试
└── examples/         一份真实报告样例
```

## 开发

```bash
.venv\Scripts\python.exe -m pytest skills/stock-dashboard/tests/ -q
```

276 个测试，0.7 秒跑完，全部离线确定性。

项目采用「实现 → 独立审查 → 修复 → 定向复审」的循环，每个任务都经过至少一轮对抗式审查。审查在计划本身里抓出的实质缺陷包括：对线性序列断言指数均线大于简单均线（数学上两者恒等）、相对强弱指标对走平序列返回 100 而非 50（一字板会被判成极度超买）、审计意见判定漏掉最严重的两类、止损价可能高于入场价、缺失数据被静默读作干净。

## 免责

本项目是个人工具，输出不构成投资建议。

分两个概念看待它的输出：**数据置信度**说的是这些数字有多可靠，**投资确定性**是另一回事，本工具不提供后者。

尤其注意上面那三条限制。六条否决路径里有四条永久失效，意味着最该拦住你的那几道闸门现在是开的——审计意见非标、大股东高比例质押、退市风险、立案调查，这四种最该让人掉头就走的情况，这个工具一个都发现不了。

数据来自公开免费接口，可能延迟、缺失或失效。决策前请自行核对原始披露。
