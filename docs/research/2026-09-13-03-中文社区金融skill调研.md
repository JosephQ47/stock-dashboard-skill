## 一、重点项目逐条分析

### 1. xbtlin/ai-berkshire —— 四大师价值投资研究框架（★16.3k）
- URL：https://github.com/xbtlin/ai-berkshire ｜ 公众号「复利炼丹炉」，20 个 skill。
- 做什么：巴菲特/芒格/段永平/李录方法论拆成 `/investment-research`、`/investment-team`（4 Agent 并行）、`/earnings-review`、`/quality-screen`（7 条硬指标）、`/investment-checklist`（六关 + 镜子测试）、`/news-pulse`、`/thesis-tracker`、`/portfolio-review` 等。
- 框架步骤：前置「AI 研究偏见自觉」（信息丰富度 A/B/C）→ 数据收集（双源交叉验证）→ 生意本质（段永平）→ 五类护城河 → 芒格逆向失败路径表 → 管理层复盘 → 李录文明趋势 → 估值（反向 DCF + 三情景 + 终值 PE = (1-g/ROIC)/(r-g)，C1 币种一致/C2 r−g≥5pct/C3 离散风险不进折现率）→ 决策备忘录（空仓者/持仓者/加仓/卖出分层建议）。
- 数据源规范（skills/financial-data.md）：A股 = 东方财富（主）+ 巨潮（副）；港股 aastocks + macrotrends；美股 macrotrends + stockanalysis + SEC EDGAR；关键数据双源，误差 >1% 标记、>5% 查原始财报；区分复权口径。
- 输出：Markdown 报告，四维评分总表、分层建议表、四大师模拟点评；准出前 `tools/report_audit.py` 抽检 15% 数据点。
- 借鉴：算术强制走 `tools/financial_rigor.py`（Decimal），禁止心算；市值 = 股价×总股本 手动验算防单位错误；「AI 置信度 ≠ 投资确定性」；8 条红线一票否决；多 Agent 用「能互相矛盾的视角」。

### 2. HKUDS/Vibe-Trading —— 90 个金融 Skill 集合（★33.3k）
- URL：https://github.com/HKUDS/Vibe-Trading ｜ 港大，`agent/src/skills/` 90 个 SKILL.md。

- `ashare-pre-st-filter`：ST 风险预测——板块阈值（主板营收 3 亿/市值 5 亿，创业板科创板 1 亿/3 亿）、红线 R1-R4（min(归母, 扣非)）、E1 审计意见/E2 监管处罚/E3 一元退市；「风险等级 + 可信度」双轴。
- `eastmoney`：东财免鉴权接口索引，按源 IP 限速≥1s。
- `investor-lenses`：12 个透镜（段永平、冯柳、邱国鹭等），叠加协议（最多 3 个、禁止平均投票、必须转述失败方最强论点）。
- `research-discipline`：60 秒偏见自检（龙头/英文/叙事/确认/近因偏好）。
- 借鉴：勾稽公式与红旗表；「数据层 skill 与分析层 skill 分离」；双轴输出。

### (b) A股特有分析点

1. 股东/供给端：解禁（>20% 流通）、减持新规、预披露、质押、股东户数、十大股东变动。
2. 财报红旗：存贷双高、应收增速 > 营收、商誉/净资产 >30%、在建不转固、资本化率高、扣非/归母 <50-70%、关联交易、少数股东损益异常、非标审计、换审计师、CFO/净利 <0.8。
3. 合规/退市：ST 红线（板块差异阈值、min(归母,扣非)）、监管函、1 元退市。
4. 资金面与情绪：主力（软）、龙虎榜、两融、涨停家数、连板封单、板块轮动、北向（受限）、量比/换手。
5. 制度：T+1、涨跌停 10%/20%/5%、政策市、壳价值、季度同比、并表变化、银行保险不适用通用勾稽。
6. 估值本土参数：WACC（消费 8-10%、科技 10-13%）、r 6-9% 与 g ≤2%、周期股用 PB/EV-EBITDA、PE-Band 五年分位、PB-ROE 矿阵。

### (c) 个人双语 Skill 设计建议

目录结构：
```
finance-analysis/
├── SKILL.md                 # 触发条件、工作流、硬规则、错误处理
├── references/
│   ├── data-sources.md      # 数据源优先级/降级链/可靠性分级/限速
│   ├── statement-analysis.md# 勾稽公式、盈利质量评分卡、12 红旗、杜邦
│   ├── a-share-checklist.md # 解禁减持/ST 红线/监管处罚/商誉应收
│   ├── valuation.md         # 方法决策树、A股 WACC、估值陷阱、三情景
│   ├── lenses.md            # 巴菲特/芒格/段永平/冯柳/邱国鹭 透镜
│   ├── glossary.md          # 中英术语对照
│   └── output-template.md   # 报告模板（中/英）
└── scripts/
    ├── fetch_data.py        # 统一取数 + 降级 + JSON + data_sources 状态
    ├── financial_rigor.py   # Decimal 精确计算、市值验算、勾稽校验
    └── report_audit.py      # 抽检报告数字
```

工作流骨架：Step 0 偏见自检 + 信息丰富度评级 + 今日日期 → Step 1 解析输入（市场识别；名称→代码用 WebSearch）→ Step 2 脚本取数（一次调用；硬/软标签；限速）→ Step 3 计算层（脚本）→ Step 4 分析层（A股清单 → 财报质量 → 护城河 → 逆向失败路径 → 估值 ≥2 法 → 透镜叠加 ≤3）→ Step 5 输出（30 秒速览 → 评分表 → 红旗 → 估值区间 → 分层建议 → 双轴结论 → 来源与缺失 → 免责）。

硬规则：禁止心算；双源误差 >1% 标注 >5% 查公告；缺失不推测；机械年化降可信度；软指标带口径警告；结论明确但区分 AI 置信度与投资确定性；中文默认、术语首次附英文、币种随市场。

可直接复用：Vibe-Trading 红旗表与现金流矩阵、决策树与陷阱表、ST 阈值表；ai-berkshire 双源规范、financial_rigor 思路、终值三约束、抽检；TradingAgents-astock 三角色必采清单；digoal 术语词典与自检；ashare-mcp 可靠性边界表。
