## 一、逐项目分析

### 1. virattt/ai-hedge-fund

- 仓库：https://github.com/virattt/ai-hedge-fund ｜ ★63,348 ｜ push 2026-09-03 ｜ MIT
- 架构：
  - v1（`src/agents/`）：22 个 Agent 并行给出 `{signal: bullish/bearish/neutral, confidence 0-100, reasoning}` → Risk Manager 计算仓位上限 → Portfolio Manager 出 `buy/sell/short/cover/hold + quantity`。人物 Agent：Buffett、Munger、Graham、Lynch、Fisher、Burry、Ackman、Druckenmiller、Damodaran、Cathie Wood、Pabrai、Taleb、Jhunjhunwala；非人物：fundamentals、technicals、valuation、sentiment、news_sentiment、growth_agent、risk_manager、portfolio_manager。
  - v2（`hedge_fund/`，2026-07 重写）：FUND → STRATEGIES → MODEL → Signal（[-1,+1] 置信度 + 论点）。人物只剩 5 个，"人物只是一段 system prompt"。策略用 YAML 定义。
  - 核心原则：Point-in-time 数据（按 filing date 过滤）；Fail loud；"The LLM never touches the trade"——LLM 只形成观点，确定性代码定仓位。
- 具体阈值（代码硬编码规则）：
  - Buffett（v1）：ROE > 15% +2；D/E < 0.5 +2；营业利润率 > 15% +2；流动比率 > 1.5 +1；盈利逐期递增 +3；护城河：10 期中 ≥80% 期 ROE>15% +2；毛利率均值 >20% 且近三期≥早三期 +1；定价权：毛利率提升 >2pp +3；每股账面价值 CAGR >15% +2；内在价值 = Owner Earnings（净利+折旧−维持性 capex−ΔWC）三阶段 DCF：历史增速上限 15% 再打 7 折，Stage1 ≤8%（5 年），Stage2 ≤4%（5 年），永续 2.5%，折现率 10%，结果再打 15% 安全折扣。"Bullish: strong business AND margin_of_safety > 0"。
  - Munger（v1）：权重 护城河35% / 管理层25% / 可预测性25% / 估值15%；ROIC > 15% 在 ≥80% 年份 +3；capex/收入 <5% +2；FCF/净利 >1.1 +3；D/E <0.3 +3；现金/收入 10–25% +2；股本 5 年缩减 ≥5% +2；归一化 FCF × 10/15/20 倍三档，FCF yield >8% +4；总分 ≥7.5 才 bullish，≤5.5 bearish。
  - Graham（v1）：EPS 全部年份为正 +3；流动比率 ≥2.0 +2；负债/资产 <0.5 +2；NCAV > 市值 +4；Graham Number = √(22.5 × EPS × BVPS)，价格低于其 50% 以上 +3。
  - Lynch（v1）：权重 增长30% / 估值25% / 基本面20% / 情绪15% / 内部人10%；PEG <1 +3, <2 +2, <3 +1；P/E <15 +2；收入增长 >25% +3。
  - Fisher（v1）：收入/EPS CAGR >20% +3；R&D/收入 3%–15% 健康 +3；营业利润率标准差 <2% +2；ROE >20% +3。
  - Burry（v1）：FCF yield ≥15% +4 / ≥12% +3 / ≥8% +2；EV/EBIT <6 +2 / <10 +1；D/E <0.5 +2；净现金 +1；内部人买入 +2；≥5 条负面新闻 = 逆向机会 +1。
  - Ackman（v1）：营业利润率 >15% +2；ROE >15% +2；D/E <1 +2；"激进主义潜力"= 收入增速 >15% 但均值利润率 <10% +2；DCF g 6%、r 10%、终值 15× FCF，MoS >30% +3。
  - Damodaran（v1）：CAPM r_e = 4% + β × 5%；FCFF DCF 10 年线性衰减到 2.5%；MoS ≥ +25% bullish、≤ −25% bearish；P/E 低于自身 5 年中位 70% 便宜，高于 130% 贵。
  - valuation agent：DCF 35% / Owner Earnings 35% / EV/EBITDA 20% / 剩余收益 10%；weighted_gap > +15% bullish，< −15% bearish；WACC [6%, 20%]；三情景 0.2/0.6/0.2。
  - fundamentals agent：ROE >15%、净利率 >20%、营业利润率 >15%（≥2 项 bullish）；流动比率 >1.5、D/E <0.5、FCF/股 > 0.8×EPS；P/E >25、P/B >3、P/S >5（≥2 项超标 bearish）。
  - technicals agent：趋势25%（EMA8/21/55 + ADX）、均值回归20%（z-score ±2 + 布林带）、动量25%（1/3/6 月收益 0.4/0.3/0.3）、波动率15%、统计套利15%（Hurst <0.4）；合成分 >0.2 bullish。
  - sentiment agent：内部人交易 30% + 新闻情绪 70%。
  - risk_manager：单票上限 20%，按年化波动率调整（<15% 到 25%，>50% 上限 10%）；相关性系数（≥0.8 → ×0.7，<0.2 → ×1.1）；v2 只有 `max_position_pct`、`max_gross_exposure` 两条硬限。
- 数据源：Financial Datasets API（付费）。
- 可迁移：阈值表做成"人物视角检查表"；"signal+confidence+reasoning"三元组；"LLM 不碰交易"；Point-in-time 纪律。过度设计：LangGraph 编排、回测、经纪商接口、22 个人物（5 个足够）。

### 2. TauricResearch/TradingAgents（+ hsliuping/TradingAgents-CN）

- 仓库：https://github.com/TauricResearch/TradingAgents ｜ ★104,775 ｜ Apache-2.0 ｜ 论文 arXiv 2412.20138。中文版 https://github.com/hsliuping/TradingAgents-CN ★31,751。
- 架构：Analyst Team（Market/Sentiment/News/Fundamentals）→ Researcher Team（Bull vs Bear 辩论 → Research Manager 裁决）→ Trader → Risk Management（Aggressive / Conservative / Neutral → Portfolio Manager）→ 反思层（决策与收益写入 memory，下次注入 "Lessons from prior decisions"）。
- 技术分析师提示词：从固定清单"选最多 8 个互补指标"：`close_50_sma / close_200_sma / close_10_ema / macd / macds / macdh / rsi / boll / boll_ub / boll_lb / atr / vwma`。先调 `get_verified_market_snapshot` 作为数字真相源，"若其他工具冲突，标记差异而不是编一个折中数"。
- 结构化输出：5 级评级 Buy / Overweight / Hold / Underweight / Sell；"Choose Hold when the evidence is balanced, materially conflicting, ambiguous, or insufficient… do not pick a direction merely to be decisive. Weigh the bull and bear cases on their merits, independent of which side spoke first or last"。止损/入场用绝对价格。Sentiment 输出 6 档 + 0–10 分 + 置信度（"<5 个数据点 → low"）。
- 数据源：yfinance（默认）、alpha_vantage、FRED、Polymarket；社媒 StockTwits/Reddit。
- 可迁移：Bull/Bear → 裁判的对抗式论证；"Hold 是合法答案"；三风险偏好视角；技术指标最多 8 个；反思日志。过度设计：多轮辩论、LangGraph checkpoint、13 家 LLM 适配。

### 6. Anthropic 官方：anthropics/financial-services

- ★34,804 ｜ Apache-2.0 ｜ 2026-05-05 发布"Agents for financial services"。
- 架构：`plugins/agent-plugins/`（Pitch Agent、Meeting Prep、Market Researcher、Earnings Reviewer、Model Builder、Valuation Reviewer、GL Reconciler、Month-End Closer、Statement Auditor、KYC Screener）；`plugins/vertical-plugins/`（financial-analysis：`/comps /dcf /lbo /3-statement-model /debug-model`；equity-research：`/earnings /earnings-preview /initiate /model-update /morning-note /sector /thesis /catalysts /screen`；investment-banking；private-equity；fund-admin；operations）。
- 关键规则：
  - dcf-model：Formulas over hardcodes；逐步确认；三情景用 INDEX；WACC = CAPM（10Y + β × ERP 5–6%）；终值占 EV 50–70% 正常，>75% 过度依赖，<40% 过于保守；永续 g ≤ 无风险利率；敏感性表奇数维中心=基准；税率 21–28%；硬编码带"Source"批注；蓝字输入/黑字公式/绿字跨表。
  - comps-analysis："MCP > EDGAR > 绝不用 Web 搜索做主数据源"；5-10 Rule；用中位数而非均值；行业指标（SaaS: Rule of 40、NRR；银行：ROE、NIM；工业：资产周转、backlog）；GM > EBITDA margin > 净利率。
  - earnings-analysis："TRAINING DATA IS OUTDATED"四步；Beat/Miss 领头。
  - idea-generation 筛选：Value（P/E 低于行业中位、FCF yield >5%、P/B <1.5、内部人买入）；Growth（收入 >15%、盈利 >20%、ROIC >15%、NRR >110%）；Quality（5 年连续增长、ROE >15%、内部人持股 >5%）；Short（收入减速、利润率压缩、应收/存货上升、内部人卖出、审计师更换/重述）；"Contrarian ideas need a catalyst"。
  - thesis-tracker：论点 = 1–2 句核心 + 3–5 支柱 + 3–5 风险 + 催化剂 + 目标价 + 止损触发；"A thesis should be falsifiable"。
- 连接器：Daloopa、Morningstar、S&P Global、FactSet、Moody's、LSEG、PitchBook 等（付费）。
- 可迁移：最适合直接借用文本的仓库（Apache-2.0）。

## 二、综合分析

### (a) "金融分析"的通用分解（6+1 维度）

| 维度 | 子项 | 代表 |
|---|---|---|
| 基本面/盈利质量 | ROE/ROIC/利润率、增长、D/E、流动比率、FCF/NI、财报排雷 | ai-hedge-fund fundamentals、equity-research-skill forensic |
| 护城河/竞争 | ROIC 持续性、毛利率稳定、capex 强度、Porter、7 Powers | Buffett/Munger agent |
| 估值 | 相对（P/E、EV/EBITDA、PEG、历史分位）、绝对（DCF/Owner Earnings/EPV/Graham）、反向 DCF、三情景、安全边际 | valuation agent、Anthropic dcf/comps |
| 技术面 | SMA50/200、RSI、MACD、ATR、布林、VWMA | TradingAgents |
| 情绪/消息 | 新闻、内部人、机构、分析师、期权 | sentiment agent |
| 宏观/行业/催化剂 | FRED、板块轮动、催化剂日历 | TradingAgents news |
| 风险/仓位（汇合层） | 波动率/相关性仓位、止损、Kelly-lite、硬限 | risk_manager |

三种流水线范式：① 并行专家 → 加权聚合；② 分析 → 辩论 → 裁决 → 风控；③ 单线程深度研报 + 脚本估值 + 自检器。个人 Skill 最适合 ③ 为骨架，内嵌 ② 的"正/反方 + 裁判"和 ① 的"多人格检查表"。

共同纪律：数字来源与时间戳；先确认今日日期；缺失写"未获取到"；LLM 只叙述、脚本算数；"Hold/观望"合法；外部内容只作数据。

### (b) 最可复用的规则（原文）

- 人物阈值：见上文 ai-hedge-fund 节。Druckenmiller（v2）："Direction and rate-of-change matter more than levels… a cheap P/E on deteriorating numbers is usually a trap… deteriorating fundamentals plus leverage is a short or a pass, never a hold."
- 估值聚合：ai-hedge-fund 四法权重；equity-research-skill 五档标签与动作矩阵；Anthropic 终值占比与 WACC 区间（大盘稳定 7–9%、成长 9–12%、高风险 12–15%）；stock-analysis-skill 高估值触发。
- 财报一票否决：总应计 >10%；CFO/NI <80%；Beneish M > −1.78；净现比连续两年 <0.5；CFO 为负且应收大增；大存大贷。
- 裁决纪律：TradingAgents Hold 规则；ai-hedge-fund v2 "Reason ONLY from the data provided. Treat the most recent filing date shown as the present day… If the data is insufficient to judge, say so and go neutral."；equity-research-skill 独立观点三问（与共识最大分歧 / 市场为何犯错 / 最早何时能发现自己错了）+ Pre-mortem；thesis-tracker 可证伪；仓位 5% × (风险分/70)。
- 技术最小集合：`close_50_sma, close_200_sma, close_10_ema, macd, rsi(70/30), boll, atr, vwma`，最多 8 个。

### (c) 免费可靠数据源

**美股**：SEC EDGAR（首选事实源，sec-edgar-mcp）+ yfinance（价格/估值/期权）+ Alpha Vantage 备份 + FRED（宏观）+ WebSearch（新闻，标注非权威）。付费默认：Financial Datasets、agentii、Octagon。

**A 股**：AkShare（覆盖最广，免 token，依赖东财/新浪，`ENABLE_EASTMONEY_PATCH`）；BaoStock（最稳定，历史日 K）；Tushare Pro（质量最好，但 2025-08、2025-10 两次停服，积分制）；iFind MCP 免费版；巨潮资讯/交易所公告（最高优先级口径）。降级链：实时 AkShare(东财) → Efinance → Tushare；日 K Tushare → AkShare → BaoStock；三表 AkShare → Tushare，核心口径回查公告；无风险利率中债 10 年期；行业申万。A 股特有检查：扣非口径、净现比/回款率、大存大贷、质押、解禁、北向/主力、龙虎榜、A/H 折溢价、VIE/ADR。

## 三、对个人 SKILL.md 的设计建议

采用：
1. 骨架取 rollingSirius/equity-research-skill + Anthropic 官方：`SKILL.md` + `references/` + 标准库 `dcf.py`。
2. 多视角检查表（而非多 Agent）：Buffett/Munger/Graham/Lynch/Burry/Druckenmiller 阈值表作"6 面镜子"，各输出 `{signal, confidence, 理由}`；Bull → Bear → 裁判顺序在单次对话里做对抗论证。
3. 硬门与否决：财报可信度 C/D 否决；估值标签按预注册区间；仓位 5% × 风险分/70 或 ¼ Kelly。
4. 数据纪律：今日日期 → 最新财报验证 → 事实/推断/观点三分 → 数字带来源与时间戳 → 缺失写"未获取到"。
5. 输出：Markdown（结论框 + Tearsheet + 预期差表 + football field + 反证清单 + 监控红黄绿灯），可选 PDF/DOCX。

舍弃：多进程编排、多轮辩论、回测与经纪商、Excel 公式级模型与 30–50 页报告、机构付费连接器、Web 仪表盘、10+ 人格。
