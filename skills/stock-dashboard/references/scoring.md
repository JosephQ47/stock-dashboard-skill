# 双轴评分方法论

数字与逻辑全部来自 `scripts/scoring.py`。质量轴（Q）回答「值不值得拿」，
时机轴（T）回答「现在是不是时候」。两轴不合并成单一数字，矛盾时必须显式
报出，禁止调和成模糊的「持有」。

## Q 轴：质量轴（0-100）

`QUALITY_WEIGHTS` 五个维度：

| 维度 | 权重 | 主要指标 |
|---|---|---|
| 财报质量与排雷（statement） | 30 | 净现比、应计比率、应收与营收增速差、商誉占净资产、扣非占归母比等红旗判定的综合命中率 |
| 盈利能力与成长（profitability） | 25 | 净利率代理（`derive_quality_dims` 中每 1 个百分点净利率对应 2 分浮动，0% 记 50 分） |
| 财务健康（health） | 15 | 权益比率（所有者权益 / 总资产）代理财务健康度，权益占比越高分越高 |
| 护城河与竞争地位（moat） | 15 | 设计上对应 ROIC 持续性、毛利率稳定度、资本开支强度 |
| 估值水平（valuation） | 15 | 设计上对应 PE/PB 五年分位、PEG、EV/EBITDA 对同业 |

**当前实现的重要缺口**：`scripts/compute.py` 的 `derive_quality_dims` 目前
只实际计算了 `statement`、`profitability`、`health` 三个维度，`moat` 与
`valuation` 在任何市场都没有被计算，从不写入维度字典。`scoring.quality_score`
调用的 `_weighted` 函数只对「在场」的维度加权、按在场维度的权重之和重新
归一（见下方计算规则），因此 Q 轴分数目前始终只由 30+25+15=70 份权重
（statement、profitability、health）重新归一得出，moat 与 valuation 的
15+15=30 份权重从未参与计算。写报告时必须提示这一点：Q 轴分数目前只反映
三个维度，不是完整的五维评估。

## T 轴：时机轴（0-100）

`TIMING_WEIGHTS` 五个维度：

| 维度 | 权重 | 主要指标 |
|---|---|---|
| 趋势（trend） | 30 | 价格相对 MA20/MA60/MA120 位置：以 50 分为基准，高于 MA20 加 20 反之减 20，高于 MA60 加 20 反之减 20，MA120 存在时高于加 10 反之减 10 |
| 动量（momentum） | 25 | RSI14 本身作为基础分（截断到 0-100），MACD 柱状值为正加 15、为负减 15 |
| 量能与资金（volume） | 20 | 量比（当日成交量 / 5 日均量）：以 50 分为基准，`(量比 - 1) * 40` 作为浮动 |
| 位置（position） | 15 | 布林带 `pct_b`（价格在布林带中的相对位置）：`100 - pct_b * 100`，越靠下轨分越高 |
| 催化与情绪（catalyst） | 10 | 设计上对应财报日历、解禁减持、新闻情绪 |

**当前实现缺口**：`derive_timing_dims` 目前只计算 `trend`、`momentum`、
`volume`、`position` 四个维度，`catalyst`（10 份权重）从未计算。T 轴分数
同样是缺项维度重新归一的结果，写报告时一并说明。

## 计算规则（`_weighted`）

对某一轴的维度字典 `dims`：

1. 只保留同时满足「在权重表中定义」且「值非 None」的维度，记为 `present`
2. `missing` 为权重表中存在但 `present` 里没有的维度名列表
3. 若 `present` 为空，整轴得分为 0.0，且 `missing` 为全部维度
4. 否则：`total_weight = sum(weights[k] for k in present)`，
   `score = sum(present[k] * weights[k] for k in present) / total_weight`
5. `breakdown` 记录每个在场维度对总分的实际贡献

也就是说，缺失维度不会被当作 0 分拖累总分，而是被从分母中一并剔除——这是
「省略比编造一个占位分更诚实」的设计取舍，但代价是分数的可比性会随「哪些
维度算出来了」而变化，两次评分如果算出的维度集合不同，分数不能直接比较。

## 一票否决

**六条否决触发条件**（对应 `ratios.py` 中 `veto=True` 的四类红旗，加下方
两条阈值规则）：

- 净现比连续两年低于 0.5（`CASH_PROFIT` 标记为 veto 的条件）
- 大存大贷：货币资金占总资产比例 > 30% 且有息负债占总资产比例 > 30%
  （`BIG_DEPOSIT_LOAN`）
- 审计意见非「无保留」（`AUDIT_OPINION`）
- 股权质押比例 > 50%（`PLEDGE`）
- 存在退市风险（`DELISTING_RISK`）
- 存在立案调查（`INVESTIGATION`）

`ratios.veto_triggered(flags)` 只要任意一条 `flag["veto"]` 为真，即返回
`True`。

**后果**（`scoring.apply_veto` 与 `scoring.map_matrix`）：

- Q 轴分数被 `apply_veto` 封顶到 `VETO_CAP = 40.0`（`min(q, 40.0)`，若 q 本身
  低于 40 则维持原值不变，不会被抬高）
- 结论强制为 `"回避"`（`VERDICT_AVOID`），`conflict` 字段固定写
  「触发一票否决，无论评分高低一律回避」
- 看板顶部必须用红字标出触发的否决原因与证据来源（对应触发红旗的 `detail`
  字段）

**当前实现的关键限制**：六条否决条件里，`AUDIT_OPINION`、`PLEDGE`、
`DELISTING_RISK`、`INVESTIGATION` 四条在当前流水线中对任何市场都没有接入
数据源（详见 `references/fundamentals.md` 与 `sources_hk_us.py` 中的
`STRUCTURALLY_UNAVAILABLE_FLAGS`），永远读到「未获取到」、`hit=False`、
`veto=False`。也就是说六条否决线里，实际能被触发的只剩「净现比连续两年
低于 0.5」与「大存大贷」两条，且两条都依赖财报三表数据成功抓取。一票否决
机制目前大部分时间处于休眠状态，不代表公司真的没有这些问题，只代表流水线
看不到——这是写报告时必须向用户明确提示的最重要限制之一。

## 60 与 45 两条分界线

`HIGH = 60.0`，`SPECULATION_FLOOR = 45.0`。

- `HIGH`（60）：Q 轴或 T 轴达到此线视为「达标」（`q_high = q >= 60`，
  `t_high = t >= 60`）
- `SPECULATION_FLOOR`（45）：仅在 T 达标但 Q 不达标时使用，用来区分「短线
  博弈」与「回避」——Q 在 [45, 60) 之间标为短线博弈，Q < 45 直接回避

## 矩阵映射四格文案

`map_matrix(q, t, veto)`，veto 为真时直接返回「回避」，不再看矩阵。否则：

| | T ≥ 60 | T < 60 |
|---|---|---|
| Q ≥ 60 | `重点关注，可建仓` | `加入候选池，等技术面转好` |
| Q < 60 且 Q ≥ 45 | `短线博弈，不是投资` | `回避` |
| Q < 45 | `回避` | `回避` |

四条判定结论字符串必须逐字复用，不得改写或意译：

- `重点关注，可建仓`
- `加入候选池，等技术面转好`
- `短线博弈，不是投资`
- `回避`

## 两轴矛盾必须显式化

`map_matrix` 在以下两种情形下会生成 `conflict` 说明文字，看板必须原样呈现
或基于其含义改写为一句话，不得省略或调和成「持有」：

- Q 达标但 T 不达标：「基本面达标（Q x.x）但技术面未转好（T x.x），等趋势
  确认再谈」
- T 达标但 Q 不达标且 Q ≥ 45：「技术面强势（T x.x）但基本面不达标（Q
  x.x），是博弈不是投资」
- T 达标但 Q 不达标且 Q < 45：「技术面强势（T x.x）但基本面太弱不足投资
  （Q x.x），坚决回避」

两轴同向（都达标或都不达标）时 `conflict` 为 `None`，此时不需要矛盾说明，
但仍需在看板中写出双轴各自的分数与结论依据。

**硬规则**：无论矛盾与否，禁止把结论写成「持有」「观望」这类模糊表述来
回避矩阵映射给出的四个固定文案之一；如果两轴信息不足以计算（如维度全部
缺失导致 `_weighted` 返回 0 分），也应如实标注「数据不足，无法评分」，而
不是编造一个中性分数。
