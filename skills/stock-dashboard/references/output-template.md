# 看板输出模板

本模板对应 spec 第 8 节列出的十二个板块，落盘路径为
`reports/{YYYY-MM-DD}-{代码}-看板.md`，同日重跑加 `-2` 后缀，不覆盖历史。
写入报告前，将占位符替换为 `compute.py` 输出与 `references/` 中对应方法论
解读的实际内容；无法替换的占位符必须显式写「未获取到」或「数据不足」，不
得删除段落或留空不说明。

模板中三处必须视觉上不可忽略：

1. **硬数据 / 软数据分区**：每张表格标题旁注明 `【硬数据】` 或
   `【软数据·附口径警告】`，不得混排
2. **因数据被阻断导致的「回避」不是对公司的判断**：顶部结论框与一票否决
   警示区分「数据阻断型回避」与「基本面/技术面判断型回避」两种性质不同的
   回避，前者必须用专门措辞说明这不是对公司的负面判断，只是数据不足以下
   结论
3. **红旗「未获取到」≠ 已核查且清白**：财报排雷表格中，「未获取到」必须
   使用独立于「✓ 未命中」的标记（如 `⬜`），并在表格下方统一注明含义

---

## 12. 免责声明

本报告由自动化脚本取数、计算，并结合固定方法论生成，仅供个人参考，不构成
投资建议、不构成对标的证券的推荐或劝诱。请注意区分以下两个独立维度：

- **数据置信度**：反映本次取数的完整性与可靠性（见完备率、硬软数据标
  注、⬜ 未获取到标记），数据置信度低不代表公司基本面差，只代表本次能看
  到的信息不够
- **投资确定性**：反映在数据充分的前提下，基本面与技术面呈现出的确定性
  高低（见 Q/T 分数、一票否决触发与否），投资确定性低也不代表数据有问
  题，可能是数据齐全但结论本身就存在不确定性

两者独立存在，不能互相替代：数据置信度高不保证投资确定性高，投资确定性
高的判断也可能建立在数据置信度不足的基础上，务必分别看待。最终决策请自行
